What it does

A supporting tool for Maritime Entry Research.

  • Search projects and organizations by product, mission or region.
  • Inspect who bought, supplied or delivered a project.
  • Trace each lead to its source; save notes and shortlists locally.

How I used AI

AI coding tools helped implement the workflow. I defined the behavior, reviewed the code and checked the interface.

The working tool

A local application built with React, FastAPI and SQLite. Source worksheets stay read-only.
